Installation & Startup

Steps to Run

Download the SecureOne Control Panel ZIP binary package and unzip it.

cd /secureone chmod +x run-local.sh ./run-local.sh

The application automatically starts and opens in your default web browser.

Initial Access

  • Login page opens with default credentials.
  • On first login, password reset is mandatory.
  • After password update, user is redirected to SecureOne Dashboard.

What to Secure

Tokens

Store registration, upload, and heartbeat tokens in a secure secret store.

Agent UUIDs

Treat UUID mappings as sensitive operational metadata and control access.

Credentials

Rotate default and integration credentials as part of onboarding.
