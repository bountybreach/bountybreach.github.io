Docker Setup and Run: SecureOne

Use the scripts below for a fast local setup on Docker.

Download scripts: docker-run-local.sh · docker-start.sh

Windows

  1. Click the Windows Start icon.
  2. Type Windows PowerShell and open it.
  3. Go to your downloads folder and run docker-run-local.sh v3.0.4.

macOS / Linux

  1. Go to downloads and get docker-run-local.sh.
  2. Run: ./docker-run-local.sh v3.0.4
  3. If Docker images are not present locally, run: ./docker-start.sh v3.0.4
